## Special System Features

### Graph Details (Colombo 1-15 City Map)

We selected the **Colombo City Map** to build our graph. Colombo is Sri Lanka's
commercial capital, and its 1–15 numbered zones are well-known, clearly
defined areas connected by a realistic road network — which makes it a
practical and relatable choice for demonstrating graph traversal (BFS/DFS)
on real-world data. We added a **Rough 2D Map** and an **Adjacency Matrix**
to visualise the connections between the zones.

The graph is **undirected**: every road works in both directions, and the
program stores each road twice in the adjacency matrix.
